# ScamGuide compliance update

## Goal
Preserve the current professional design while making every page clearly identify ScamGuide as an independent educational resource, not a support provider.

## Implementation
- Add a shared ScamGuide header and footer linking Home, Safety Guide, About, Contact, Privacy Policy, Terms, and Disclaimer.
- Revise the homepage headline, calls to action, introductory notice, and About section while retaining the long-form safety guide.
- Mark every simulated warning with a large diagonal red “FAKE” overlay, a written simulation label, and fictional-details disclosure where applicable.
- Create About, Contact, Privacy Policy, Terms of Use, and Disclaimer pages with distinct educational copy and page metadata.
- Build the contact form with email/message validation, required privacy acknowledgement, sensitive-information warning, a hidden bot trap, and a clear owner-email placeholder because no delivery address was supplied.
- State accurately that the site currently uses no analytics, advertising trackers, or non-essential cookies; do not add a consent banner.
- Verify links, essential page content, and layouts on desktop and mobile.

## Cost control
Reuse the existing design and illustrations, make changes in one focused pass, avoid generated media and new paid services, and run only essential checks.
